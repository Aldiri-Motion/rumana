# موقع رمانة

موقع ثابت (HTML/CSS/JS) بدون أي برامج إضافية. بيشتغل على أي استضافة (Netlify, Vercel, GitHub Pages, cPanel...).

## الملفات
- `index.html` الصفحات كلها (الرئيسية، من نحن، منتجاتنا وأقسامها، ليش رمانة، كيف تطلب، التوصيل والاستلام، تجارب عملائنا، تواصل معنا)
- `assets/data.js` **هون بتعدّل كل شي متغيّر**: رقم الواتساب، روابط إنستغرام وفيسبوك، المنتجات، تجارب العملاء، نقاط الاستلام
- `assets/products/` حط صور المنتجات هون
- `assets/style.css` و `assets/app.js` التصميم والبرمجة

## إضافة منتج
داخل القسم المناسب في `data.js`:
```js
{ name: "برواز خشب 20×30", desc: "وصف قصير", price: 60, img: "assets/products/frame-1.jpg" }
```
إذا ما في سعر ثابت اترك `price` فاضي وبيظهر "السعر حسب الطلب".

## روابط الأقسام
`#frames` البراويز · `#gifts` هدايا رمانة · `#mugs` المجات · `#photos` الصور · `#favors` توزيعات مناسبات · `#stickers` الستيكرات والملصقات

## السلة والطلب
الزبون بيضيف منتجات للسلة، بيعبّي اسمه ورقمه وطريقة الاستلام، وبتنفتح محادثة واتساب فيها الطلب كامل مع المجموع. لازم تعبّي `whatsapp` في `data.js` حتى توصل الرسائل إلك.
- `deliveryNote` في `data.js`: سعر التوصيل اللي بيظهر بالسلة
- `faq` في `data.js`: الأسئلة الشائعة

## الرفع على rumana.ps
ارفع المجلد كامل كما هو (Cloudflare Pages أو Netlify: اسحب المجلد وافلته). الملفات `robots.txt` و`sitemap.xml` و`404.html` جاهزة.
